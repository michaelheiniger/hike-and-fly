## Diagrams

The diagrams in [`diagrams/`](diagrams) are `.drawio.svg` files: SVG images with the draw.io
model embedded. GitHub shows them as images. To edit one, open it in
[draw.io](https://app.diagrams.net) (File → Open) or with the VS Code *Draw.io Integration*
extension, then save it as the same `.drawio.svg` file: draw.io keeps the image and the model
in sync.
